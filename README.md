One haiku about debugging, in 5-7-5 syllables: a cursor blinking past three in the morning, a log that swears the code is fine, and a last line that turns the blame back on the debugger. `main.py` writes the haiku as plain text to `entry.txt` in the output directory — deterministic, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
